# Manticore Games

> Manticore Games is a San Mateo-based game developer and publisher, and the studio behind Core — a free, Unreal Engine-powered game-creation platform and metaverse where a global community of creators builds, publishes, and plays multiplayer games and experiences. Core exposes a Lua scripting API for programming game logic directly in the editor. It is not an HTTP/REST API; code runs inside the Core runtime. Manticore is backed by SoftBank Vision Fund.

## Core Lua Scripting API
